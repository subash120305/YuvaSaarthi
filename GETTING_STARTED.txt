                            ⚡ QUICK START

STEP 1: Run Setup (2 minutes)
------------------------------
Open Command Prompt in this folder and run:

    setup.bat

This installs everything you need.


STEP 2: Get Groq API Key (2 minutes)
--------------------------------------
1. Go to: https://console.groq.com
2. Sign up (use Google/GitHub)
3. Click "Create API Key"
4. Copy the key (starts with gsk_)


STEP 3: Add API Key (1 minute)
-------------------------------
1. Open ".env" file in this folder
2. Find line: GROQ_API_KEY=your_groq_api_key_here
3. Replace with: GROQ_API_KEY=gsk_your_actual_key
4. Save the file


STEP 4: Create Sample Data (2 minutes)
---------------------------------------
Run this command:

    python create_sample_data.py

This creates sample educational PDFs for testing.


STEP 5: Process Documents (2 minutes)
--------------------------------------
Run this command:

    python ingest_documents.py

Type "yes" when asked. This builds the knowledge base.


STEP 6: Start Your Chatbot! (1 minute)
---------------------------------------
Choose ONE:

  A) Web Interface (Recommended for Demo):

     streamlit run streamlit_app.py

     Browser will open automatically!

  B) Telegram Bot:

     python telegram_bot.py

     (Need Telegram bot token first - see API_SETUP.md)

================================================================================
                        📁 ADDING YOUR OWN PDFS
================================================================================

1. Put your PDF files in:  data\documents\textbooks\

2. Name them like:
   - class_10_mathematics.pdf
   - class_11_physics.pdf
   - class_12_chemistry.pdf

3. Run:  python ingest_documents.py

4. Done! Now ask questions about your PDFs.

                          ❓ NEED HELP?
================================================================================

Problem: "Python not found"
Solution: Install Python from python.org (version 3.9 or higher)

Problem: "Groq API error"
Solution: Check your API key in .env file

Problem: "No documents found"
Solution: Run: python create_sample_data.py

Problem: "Module not found"
Solution: Run: setup.bat again
